# FRAME — утверждённый дизайн

Создать этап A: кинематографичный редакционный прототип на Next.js App Router, TypeScript, Tailwind, Lucide и Motion. Главная с атмосферным изображением, выразительной типографикой и поиском. Четыре локальных фильма: Интерстеллар, Дюна: Часть вторая, Чебурашка, RRR.

Карточка: кадр и постер; сведения; премьеры с фильтрами; финансы с метаданными источника; видео; галерея; производство; демонстрационный ассистент. Все неподключённые показатели явно обозначены как демонстрационные. Отсутствующие сведения не придумываются.

Цвета: #0D0F11, #171A1E, #F3F1EA, #A5AAB0, #CDB58A. Шрифты: Onest и Cormorant Garamond. Тон: спокойный, редакционный, точный. Отличительная черта: крупный заголовок и кинематографичный простор вместо карточной сетки.

Архитектура: интерфейс → MovieDetail → провайдеры → серверные API. Ключи только в окружении сервера. IMDb/BoxOffice/TMDB/AI — контракты для последующего подключения. На этапе A запросы к платным API отсутствуют.

Проверки: TypeScript, production build, поиск на двух языках и клавиатура, фильтры, модальные окна, отсутствие горизонтального переполнения на смартфоне. Пользователь утвердил 10 октября 2026.
