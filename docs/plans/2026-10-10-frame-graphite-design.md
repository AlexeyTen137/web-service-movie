# FRAME — графитовый вариант

Изменения по обратной связи: строгая, компактная карточка с приоритетом телефона. Графитово-серый фон с едва заметной процедурной текстурой; нейтральный металлический поиск, чёткие края, тонкие линии и минимум декоративных подписей.

FRAME расположен по центру над полем поиска высотой 58 px. У каждого фильма используется собственный backdrop из данных карточки. Постер увеличен; заголовок показывает оригинальное название / русское, год выделен отдельно. Длительность, возраст и жанры сгруппированы рядом с постером.

Кнопка трейлера компактна; сохранение — только иконка справа. Разделы фильма раскрываются без лишних отступов. Premieres — компактный список двух основных дат. Кассовый блок содержит сумму, стрелку, отношение к бюджету и график; декоративный заголовок удалён. Команда, актёры и технические сведения собраны без округлых карточек.

Для Интерстеллара добавлены опубликованные оценки IMDb 8.7/10, Rotten Tomatoes 73% критики и 87% зрители, Metacritic 74/100. Каждая оценка ведёт на первоисточник. Это независимые шкалы; единый мировой рейтинг не вычисляется. Значения сохранены вручную, автоматические API не подключены.

Проверены мобильные ширины 320 и 390 px и раскрытие дат премьер.
