# FRAME — кино в деталях

Этап A: визуальный прототип международного кинопортала. Next.js 16.4, React 19.3, TypeScript, Tailwind 4.3, Lucide, Motion. Компоненты Button/Dialog в стиле shadcn/ui; доступные модальные окна на Radix Dialog.

## Локальный запуск

```sh
npm install
npm run dev
```

Открыть http://localhost:3000. Для production: `npm run build`, затем `npm start`. Проверка типов: `npm run typecheck`.

Если путь к проекту содержит `#`, `scripts/run-next.cjs` автоматически готовит копию в системной временной папке: текущие версии Next/Tailwind неправильно обрабатывают этот символ в путях. Исходники остаются в проекте; изменения в app/components/lib/public синхронизируются при разработке. При изменениях конфигурации или окружения перезапустите сервер. Зависимости копируются только после изменения lock-файла.

## Реализовано

- Главная с кинематографичным изображением и поиском по русским/английским названиям; подсказки, стрелки, Enter, Escape, Cmd/Ctrl+K.
- Четыре фильма: Интерстеллар, Дюна: Часть вторая, Чебурашка, RRR.
- Премьеры: поиск страны, регионы, типы релиза, порядок дат с группировкой по стране, раскрытие списка, отсутствующие даты.
- Финансы с указанием статуса, источника, даты; сравнение сборов и бюджета, без приравнивания к прибыли.
- Несколько видеороликов, YouTube privacy-enhanced player, внешняя ссылка при недоступности встраивания.
- Галерея с фильтрами и модальным просмотром; производство и ссылка на технические сведения IMDb.
- Демонстрационный помощник через серверный endpoint, отметка фильма в localStorage.
- Адаптивность, lazy loading второстепенных изображений, reduced motion, loading/error/empty состояния, focus trapping и возврат фокуса в модальных окнах.

## Демоданные и ограничения

Карточка «Интерстеллара» заполнена вручную сведениями из открытых источников: Box Office Mojo (финансы и региональные релизы), The Numbers (ограниченный и широкий прокат в США), Rotten Tomatoes (зрительские оценки, звуковые форматы), Википедия (мировая премьера, команда и общие сведения), American Cinematographer / ASC (сочетание IMAX и 35-мм съёмки). Это сохранённый снимок источников, просмотренных 10.10.2026, без автоматического обновления и без утверждения об официальной верификации. Мировые и внутренние сборы включают повторный прокат.

В остальных фильмах даты премьер, рейтинги и финансовые числа — демонстрационные примеры. Локальные сведения о фильмах и команде не прошли подключённую верификацию. Финансовые/технические поля имеют Source (name, asOf, status, url). Для Чебурашки и RRR предусмотрены эстетичные постеры-заглушки; финансовые сведения отсутствуют. Видео и изображения — выбранные демонстрационные материалы, а не полный каталог. Обложки видео используют кадр фильма. Доступность YouTube зависит от страны и ограничений видеопровайдера.

Изображения локально сохранены с TMDB image CDN. FRAME не одобрен и не сертифицирован TMDB. Перед публикацией необходимо проверить права использования материалов и условия источников. Google Fonts загружаются через CSS с запасными шрифтами при отсутствии сети.

Помощник сейчас выдаёт детерминированные ответы из локальной карточки: настоящая языковая модель не подключена. Ему нельзя приписывать работу Gemini/OpenRouter.

## Архитектура и следующий этап

`lib/types.ts` — нормализованный MovieDetail; `lib/movies.ts` — локальный набор; `lib/providers` — MockMovieProvider, MockAIProvider и контракты TMDBProvider, IMDbProvider, BoxOfficeProvider, AIProvider; `app/api` — search, movies/[id], assistant; `components` — интерфейс.

Копировать `.env.example` в `.env.local` можно перед будущей интеграцией. Переменные сейчас документируют будущие настройки; добавление ключа само по себе не включает API. TMDB и ИИ адаптеры следует реализовать на этапе B/C после утверждения визуального прототипа. IMDb и Box Office Mojo требуют согласованного лицензированного доступа, схемы и полей.

Ответы поиска и карточек имеют HTTP cache headers; API ограничен 120 запросами в минуту на процесс. Для локального прототипа этого достаточно. При production-развёртывании нужен общий rate-limit store и отдельные лимиты по клиентам. Ключи не имеют NEXT_PUBLIC-префикса, провайдеры защищены server-only.

Следующий минимальный шаг: утвердить внешний вид в браузере, затем подключить TMDB для реального поиска и достоверных карточек.
